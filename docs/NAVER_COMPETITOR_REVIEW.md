## 두들펫 확인 사항

- `site:pet.dudle.co.kr` 네이버 첫 페이지에 홈, 서울/부산 진료비, 제주 병원/약국, 울산 약국이 관찰되었다. 사이트 전체 미색인은 아니다. 전체 색인 수는 이 검색으로 산정할 수 없다.
- 여수 병원 실제 페이지에는 15곳, 지도 가능 15곳, 전화 확인 8곳, 공식 기준일 2026-02-11, 동기화 2026-09-05가 표시됐다. 이는 관찰 당시 페이지 값이며 최신 원본 전체 재검증 결과가 아니다.
- 이번 지역 검색 첫 페이지에서 두들펫은 확인하지 못했다. 제목·SSR·사이트맵 테스트 통과와 실제 검색 경쟁력은 별도다.
- 실제 관련정보 영역은 같은 ‘여수 지역 진료비’ 라벨 8개가 반복되고 약국 링크가 밀려 있었다. SQL이 canonical URL 알파벳순으로 LIMIT 8을 적용한 것이 직접 원인이다.

## 이번 코드 수정

1. 같은 지역의 SEO_READY/수동 보류 아님 조건을 유지하면서 병원→약국→장례→진료비 메인 페이지를 항목별 진료비보다 우선 조회한다.
2. 진료비 상세 링크는 공식 항목 카탈로그의 실제 이름을 사용한다.
3. 현재 목록으로 향하는 자기 링크, 중복·외부·query/fragment 링크를 제외한다.
4. URL, canonical, robots, sitemap, DB 값, 광고, 지도 및 인증 설정은 변경하지 않는다.

실제 DB 읽기 검증: 부산은 네 카테고리, 여수는 승인된 병원·약국·진료비 링크가 반환됐다. 여수 장례 링크를 임의 생성하지 않는다. 단위 테스트 85 passed / 1 skipped, lint/typecheck/build 통과, secret scan 0. Production 배포는 하지 않았다.

## 후속 우선순위 (아직 구현/완료 아님)

1. 네이버 서치어드바이저 URL 검사에서 부산/여수의 각 카테고리 수집·색인을 확인한다. 사이트 검색만으로 미색인 원인을 확정하지 않는다.
2. ‘지역+진료비+실제 공개 항목’부터 같은 조사연도·동물·체중의 지역/전국 비교를 제공한다. 미공개 값·다른 조건을 합산하거나 최저가 병원이라고 추정하지 않는다.
3. 병원 운영시간·진료동물, 약국 취급품목, 장례 비용·포함 서비스는 업체 공식 출처와 확인일을 확보한 뒤 보강한다. 공공 등록상 영업과 지금 진료/영업 중은 구분한다.
4. 페이지를 대량 추가하기보다 부산·여수 등 기존 핵심 지역의 실제 의사결정 정보를 먼저 개선한다. 동일한 FAQ를 지역명만 바꿔 대량 생성하지 않는다.
5. 네이버 노출/클릭 리포트 기준 기간을 기록하고 변경 전후를 비교한다. 즉시 순위 상승, 전문성 평가 원인, 검색량, 유입 증가를 미확인 상태로 주장하지 않는다.
